# ForgeHub Disable Comments

Disable comments, pingbacks and trackbacks everywhere or per post type; hide comment menus, admin bar items and feeds.

| Feature | Free | Pro |
| --- | --- | --- |
| Disable comments/pings (all or per post type) | Yes | Yes |
| Hide menu, admin bar, comment feed | Yes | Yes |
| Bulk delete existing comments | No | Yes |
| Role based rules | No | Yes |

Install: upload the zip, activate, then Settings > Disable Comments.
